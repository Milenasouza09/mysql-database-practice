# 🗄️ Projetos de Banco de Dados - MySQL

Este repositório contém projetos e exercícios desenvolvidos utilizando MySQL, com foco em modelagem de banco de dados, criação de tabelas e consultas SQL.

---

## 📂 Projetos

### 📚 Livraria
Sistema de banco de dados para gerenciamento de livros, autores e vendas.

### ✈️ Agência de Viagens
Banco de dados para controle de clientes, destinos e reservas.

### 🧪 Exercícios
Consultas SQL para prática de SELECT, JOIN, INSERT, UPDATE e DELETE.

---

## 🛠️ Tecnologias

- MySQL

## 🎯 Objetivo

Praticar e aprimorar conhecimentos em banco de dados relacional e linguagem SQL.
